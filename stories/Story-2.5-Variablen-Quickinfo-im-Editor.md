# Story 2.5: Variablen-Quickinfo im Editor

## Ziel
TeX-Variablen im Editor als Links darstellen. Beim Antippen einer Variablen soll eine Quickinfo mit ihrem aufgelösten Inhalt erscheinen.

## Teilschritte
- [ ] TeX-Variablen im Editor als Links kennzeichnen. **Ausstehend**
- [ ] Beim Antippen eine Quickinfo mit dem aufgelösten Inhalt anzeigen. **Ausstehend**
