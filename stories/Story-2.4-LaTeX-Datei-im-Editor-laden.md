# Story 2.4: Ausgewählte LaTeX-Datei im Editor laden

**Status: Ausstehend**

## Ziel
Wird eine LaTeX-Datei in der Sidebar ausgewählt, soll ihr Inhalt in den Editor geladen werden.

## Teilschritte
- [ ] LaTeX-Dateien in der Sidebar auswählbar machen. **Ausstehend**
- [ ] Beim Auswählen einer LaTeX-Datei deren Inhalt in den Editor laden. **Ausstehend**
- [ ] Die ausgewählte Datei als aktuell im Editor bearbeitete Datei kenntlich machen. **Ausstehend**
